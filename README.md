# PixelVault — Actividad Sumativa Semana 3

Sitio web responsivo de una tienda de videojuegos, desarrollado para la asignatura **PFY2201 Desarrollo Frontend I**.

## Visualización local

Abre `index.html` en un navegador. El proyecto no requiere instalación, dependencias ni conexión a internet.

## Contenidos evaluados

- HTML5 semántico: `header`, `nav`, `main`, `section`, `article`, `form` y `footer`.
- Hoja de estilos externa correctamente vinculada (`styles.css`).
- Modelo de cajas: `box-sizing`, márgenes, rellenos, bordes y dimensiones consistentes.
- Esquema visual de alto contraste, jerarquía tipográfica y estados de foco accesibles.
- Flexbox en navegación, botones, estadísticas, tarjetas y pie de página.
- CSS Grid en hero, catálogo, categorías, comunidad y formulario.
- Selectores de clase, atributos, pseudoclases, `nth-child`, `:hover`, `:focus-visible` y pseudo-elementos.
- Media queries para móvil, tablet y escritorio.
- Recursos gráficos locales y textos alternativos.
